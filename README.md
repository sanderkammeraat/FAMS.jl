# FAMS: Framework for Active Matter Simulations in Julia 

[![Build Status](https://github.com/sanderkammeraat/FAMS.jl/actions/workflows/CI.yml/badge.svg?branch=main)](https://github.com/sanderkammeraat/FAMS.jl/actions/workflows/CI.yml?query=branch%3Amain)

To install, do
1) 'using Pkg'   
2) 'Pkg.add(url="https://github.com/sanderkammeraat/FAMS.jl")'
  
You can then use it by running
using FAMS
  
For live plotting, add the import of GLMakie after the import of FAMS:
'using GLMakie'  
 
This will precompile the optional Live plotting extension.
